Dukes 隱私權政策

最後更新：2026-10-20

存取哪些資料

使用者授權後，Dukes 只會依使用者本人的要求，讀取該使用者的 Gmail 郵件與 Google 日曆內容，例如摘要信件、查詢行程。若使用者另外授權寫入權限，Dukes 只會在使用者明確同意後代為寄信或修改行程。

資料如何使用與保存

  • 資料只用來回應使用者本人的要求，不做廣告、不做分析、不用來訓練 AI 模型。
  • 不出售、不出租、不分享給任何第三方。
  • 授權憑證只保存在執行 Dukes 的私人電腦上。

Google 使用者資料

Dukes 使用與轉移從 Google API 取得的資訊，均遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

撤銷授權

使用者可隨時到 Google 帳戶的第三方存取權頁面 移除 Dukes，撤銷後 Dukes 即無法再存取任何資料。

Dukes Privacy Policy

Last updated: 2026-10-20

What we access. After the user grants access, Dukes reads that user's Gmail messages and Google Calendar only when the user asks, for example to summarize email or check a schedule. If the user grants write access, Dukes sends email or changes events only after the user explicitly approves each action.

How data is used. Data is used only to answer the user's own requests. It is not used for advertising, analytics, or training AI models, and it is never sold, rented, or shared with third parties. Authorization tokens are stored only on the private computer that runs Dukes.

Google user data. Dukes' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Users can remove Dukes at any time from the third-party access page of their Google Account.
